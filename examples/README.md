# Example data sources

The examples support local browsing and inspection of saved results.

| Material | Source and scope |
|---|---|
| Catalogue JSON | Existing metadata for 204 expression references, 829 phenotypes and 32 source records |
| RGL4 associations | Three saved gene/model/trait rows for phenotypes 464, 521.1 and 626.2 |
| UKB 411.8 excerpt | Public fastGWA summary statistics, 4,500 mapped chromosome 22 variants |
| UKB 411.8 output | Existing complete 78-gene result and 156 method statistics |
| Summary-eQTL input | One-gene file associated with Jerber et al. (2021), DOI 10.1038/s41588-021-00801-6 |
| Captured operands | Fixed vectors and covariance matrices for the numerical comparison |

Catalogue record identifiers are retained, including PheCode leading zeroes and the two Pashos 2017 source rows. Catalogue collection, study sample context and expression assay are distinct fields.

Example data retain the terms of their respective sources. Third-party frontend licenses do not assign licenses to the GWAS excerpt, summary-eQTL file, catalogue records or captured numerical inputs. Full reference weights, LD panels and individual-level data are separate resources.
