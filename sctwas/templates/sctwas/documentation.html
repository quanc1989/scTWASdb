Data organization

Expression reference models are indexed by model identifier, cellular context, condition and source study. The catalogue includes single-cell, purified-cell and bulk expression assays. The study sample size describes the reported cohort or samples. Model training N is a separate quantity.

Catalogue counts refer to entries. More than one source record can share a study ID. The reference model catalogue lists source publications and weight files by autosome.

Association records and exports

Explore associations accepts a gene symbol, Ensembl ID, rsID, trait description or cell population. Results report distinct model IDs and Ensembl IDs for each trait and the selected filters. Broad queries report progress until all candidate traits have been checked.

The precomputed association dataset legacy-db-20260917 contains nominally filtered records. A matching record can pass the nominal P filter through either association method. The complete set of tests used to derive these records is unavailable in the database.

Download all filtered rows (TSV) prepares the matching records at stored precision. Copy current page copies the visible table page. The export record gives the selection, row count, SHA-256 and expiry. Download links remain available for 24 hours after generation and support resumption.

GWAS summary statistics

Submit a gzip-compressed TSV for one autosome in GRCh38 (hg38), with a header and a maximum file size of 100 MiB.

CHROM   POS       REF   ALT   Zscore
22      22688361  C     T     -0.3651

CHROM and POS identify the chromosome and position. REF and ALT specify the reference and alternate alleles. Zscore is the signed GWAS association statistic. Check the source effect allele and align the sign with the input allele convention.

Example analysis settings

The GWAS example contains 4,500 rows from chr22 regions of UKB trait 411.8. Use chr22, hg38, EUR, model CD4+_T_cells_Schmiedel_2018_naive, a cis window of 1,000,000 bp and a weight threshold of 0. Select FUSION, SPrediXcan or both. A nominal P threshold of 0.05 displays the example results.

eQTL summary statistics

Submit a TSV with a header for the selected autosome in GRCh38 (hg38). The maximum file size is 100 MiB. Use the following columns in order.

CHROM   POS       A1   A2   Z                 TargetID         N
22      21063901  A    G    2.07743582109394  ENSG00000185651  215

A1 and A2 retain the source allele convention for the signed Z statistic. Check the effect allele before converting column labels. TargetID identifies the expression gene and N gives the sample size in the source summary statistics.

The eQTL example is a one-gene chr22 subset of D11_Stegle_2021_FPP.iPSCs with 134 variants and N = 215. Use the EUR reference for weight construction.

TWAS results contain one record per returned gene and method, with a signed Z statistic and nominal P value. The selected threshold controls the displayed and exported records. The TSV retains stored precision. Weight construction produces files for the selected method.

Statistical interpretation

TWAS Z statistics quantify the association between genetically predicted expression and a trait. Association can reflect linked signals or correlated predicted expression across models. Causal interpretation requires additional evidence.

The interface uses nominal P values. Study-wide inference requires a multiple-testing procedure defined for the tested analysis family. A gene–method record in the result table is the unit of display.

FUSION and S-PrediXcan use the selected GWAS statistics, expression weights and LD reference. The two methods share inputs. Independent replication requires an independent dataset. Match genome build, allele coding and the reference population to the analysis. The LD population and expression reference cohort are distinct parameters.

Expression weight estimation and prediction evaluation are separate steps. Prediction performance can be measured using held-out or external expression data.

Methods and source studies

TIGAR implements the FUSION and S-PrediXcan association paths. OTTERS supports PT, lassosum, PRScs and SDPR weight estimation from eQTL summary data. PT reports weights at the method's configured P thresholds.

Cite the analysis methods and source studies. Record the model identifier, GWAS source, genome build, LD population and analysis settings. Example inputs and reference metadata are listed under Downloads.
